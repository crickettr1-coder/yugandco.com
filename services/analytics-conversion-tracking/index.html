SERVICE QUESTIONS

Before we begin.

Can you review our current tracking?+

Yes. An audit can identify missing events, duplicate counts, inconsistent definitions and gaps in the enquiry journey before setup changes are recommended.

Does tracking guarantee accurate attribution?+

No. Consent choices, browser restrictions, cross-device activity and platform models can create gaps. We document limitations and avoid treating every reported conversion as a qualified lead.

Is a button click a conversion?+

It can be a useful interaction event, but it is not the same as a completed enquiry. The measurement plan should make that distinction explicit.

Can reporting identify every customer journey?+

No. Browser restrictions, consent, offline activity and multiple devices can create gaps. Reports should explain these limits.
